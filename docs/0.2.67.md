# Silique 0.2.67

## English

- The three Android launcher action widgets (**New note**, **Search**, **Journal
  entry**) no longer wrap and clip their label when the launcher squeezes them to
  one cell (it used to show "+ No…"). A widget that narrow now collapses to its
  single glyph — `+`, `⌕`, `✎` — while the default two-slot form keeps the full
  label unchanged.
- The switch is driven by `AppWidgetManager.OPTION_APPWIDGET_MIN_WIDTH`: a
  positive width below 100 dp selects the compact layout, zero or absent options
  keep the former full label. The three providers repaint from the fresh options
  bundle on `onAppWidgetOptionsChanged`, so resizing in either direction is
  immediate without reopening the app.
- The full label stays the widget's content description in both forms, so
  screen readers still announce "New Silique note" / "Search Silique" / "Silique
  journal entry" on the compact glyph.
- The interface-language refresh keeps the compact form and its glyph, and still
  never reads the encrypted widget snapshot (no Keystore access).
- No protocol, crypto, snapshot-format, database-migration, dependency or server
  changes. The same Android signing key is used, so installing over the previous
  version works normally; macOS still requires manual installation from the DMG
  (self-signed build).

## Polski

- Trzy akcyjne widżety Androida na pulpicie (**Nowa notatka**, **Szukaj**,
  **Wpis do dziennika**) nie zawijają już i nie ucinają etykiety, gdy launcher
  ściska je do jednej komórki (wcześniej widać było „+ No…”). Tak wąski widget
  pokazuje teraz sam glif — `+`, `⌕`, `✎` — a domyślna forma na dwa sloty
  zachowuje pełną etykietę bez zmian.
- O wyborze wariantu decyduje `AppWidgetManager.OPTION_APPWIDGET_MIN_WIDTH`:
  dodatnia szerokość poniżej 100 dp wybiera układ kompaktowy, zero lub brak
  opcji zachowuje dotychczasową pełną etykietę. Trzy providery przemalowują
  widget ze świeżego pakietu opcji w `onAppWidgetOptionsChanged`, więc zmiana
  rozmiaru w obie strony działa od razu, bez otwierania aplikacji.
- Pełna etykieta pozostaje opisem treści widgetu w obu formach, więc czytnik
  ekranu nadal zapowiada „Nowa notatka Silique” / „Szukaj w Silique” / „Wpis do
  dziennika Silique” przy kompaktowym glifie.
- Odświeżenie języka interfejsu zachowuje formę kompaktową i jej glif, nadal też
  nie czyta zaszyfrowanej migawki widżetu (brak dostępu do Keystore).
- Brak zmian protokołu, kryptografii, formatu migawki, migracji bazy, zależności
  i serwera. Ten sam klucz podpisu Androida, więc instalacja na poprzednią
  wersję działa normalnie; macOS nadal wymaga ręcznej instalacji z DMG
  (kompilacja self-signed).
