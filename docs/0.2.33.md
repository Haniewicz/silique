## Scope

English is the default interface language regardless of the operating-system
locale. English / Polski is selectable during initial storage setup and in
Settings, saved locally and applied live. The translation includes navigation,
menus, dialogs, storage/credential guidance, updater statuses and Android
launcher widgets/search. System/component-owned security and installer dialogs
may still follow their own OS localization.

Existing notes, vault names, folders, tags, keys, crypto/storage identifiers and
protocol fields are not translated or migrated. New default titles, templates
and the onboarding sample folder use the creation language. Deterministic
ordinary/hidden conflict-copy content preserves its legacy language-independent
wire value so mixed-language clients converge.

Optional native refresh cannot prevent notebook startup. A saved choice and a
failed native refresh are reported separately, with an explicit retry. Native
Android refresh relabels presentation without reading keys/snapshots, replacing
widget targets, or resetting an open search query/selection/results adapter.

[Implementation boundaries](LOCALIZATION.md).
