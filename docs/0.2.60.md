# Silique 0.2.60

## English

- Sidebar footer reworked: at the very bottom there is now a single row of four
  actions — Deleted, Hidden, Import and **Settings**. The vault badge that used
  to sit below them (vault name, note count and `E2EE`/`local`) is gone; the
  Settings action uses the same footer-button styling as its neighbours and is
  placed in the same line, and it closes the drawer first on phones.
- Template pickers in Settings now look like every other dropdown: the label is
  carried by the input field, its closed state stays one line, and the expanded
  menu shows the full entry.
- Templates stored in a **subfolder** of the templates folder are now listed and
  selectable (previously only notes directly in the templates root were
  offered). The picker and the Settings lists show the path relative to the
  templates folder, so same-named templates from different subfolders can be
  told apart.
- Built-in folder names now follow the application language: the templates and
  journal folders are shown as `Szablony`/`Dziennik` in Polish and
  `Templates`/`Journal` in English, new vaults seed the folder in the current
  language, and existing notes keep their stored paths. Both spellings are
  recognised as the same built-in folder (case-insensitively) for detection,
  rename/delete guards and hiding, so switching the UI language never creates a
  duplicate folder and never rewrites existing data. The localized name is also
  used in the folder tree, breadcrumbs, the quick switcher and the folder
  pickers.
- No protocol, crypto, database-migration or server changes. No new
  dependencies. Same Android signing key, so installing over the previous
  version works normally. macOS still requires manual installation from the DMG
  (self-signed build).

## Polski

- Przebudowana stopka sidebara: na samym dole jest teraz jedna linia czterech
  akcji — Usunięte, Ukryte, Importuj i **Ustawienia**. Plakietka vaulta, która
  była pod nimi (nazwa vaulta, liczba notatek i `E2EE`/`lokalnie`), została
  usunięta; akcja Ustawienia ma ten sam styl przycisku stopki co sąsiednie
  i stoi w tej samej linii, a na telefonie najpierw zamyka szufladę.
- Listy wyboru szablonu w Ustawieniach wyglądają teraz jak każda inna rozwijana
  lista: etykieta jest w polu, zamknięta lista ma jedną linię, a rozwinięte menu
  pokazuje pełny wpis.
- Szablony leżące w **podfolderze** folderu szablonów są teraz widoczne
  i wybieralne (wcześniej oferowane były tylko notatki bezpośrednio w katalogu
  głównym szablonów). Picker i listy w Ustawieniach pokazują ścieżkę względną
  wobec folderu szablonów, więc szablony o tej samej nazwie z różnych
  podfolderów da się rozróżnić.
- Nazwy wbudowanych folderów zależą teraz od języka aplikacji: foldery szablonów
  i dziennika pokazują się jako `Szablony`/`Dziennik` po polsku oraz
  `Templates`/`Journal` po angielsku, nowe vaulty zakładają folder w bieżącym
  języku, a istniejące notatki zachowują zapisane ścieżki. Obie pisownie są
  rozpoznawane jako ten sam wbudowany folder (bez względu na wielkość liter)
  przy detekcji, guardach zmiany nazwy i usuwania oraz ukrywaniu — przełączenie
  języka UI nie tworzy duplikatu folderu i nie przepisuje istniejących danych.
  Zlokalizowana nazwa jest używana także w drzewie folderów, breadcrumbach,
  quick switcherze i pickerach folderu.
- Bez zmian protokołu, kryptografii, migracji bazy i serwera. Bez nowych
  zależności. Ten sam klucz podpisu Androida, więc instalacja nad poprzednią
  wersją działa normalnie. macOS nadal wymaga ręcznej instalacji z DMG
  (build self-signed).
