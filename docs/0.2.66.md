# Silique 0.2.66

## English

- The Android launcher note list no longer clips the top of the first card. Row
  spacing moved from a layout margin on the row itself to the list (transparent
  divider plus list padding); a margin on a RemoteViews collection row is wrapped
  by the launcher, which pushed the first card onto the clip edge even with the
  list scrolled fully to the top.
- The native widget search is now a small floating dialog over the launcher that
  opened the widget instead of a full-screen window: a transparent window with a
  dimmed background and a fully opaque card, so the screen behind stays visible
  while no note text can be read through it. A tap outside closes it.
- The search window no longer covers the status bar: it is placed by the system
  inside the safe area, is narrower than the screen, and its results list is
  capped to half the display height so the query stays visible when the keyboard
  appears; the keyboard now pans instead of resizing the card.
- Privacy is unchanged: FLAG_SECURE stays, the card is opaque, and no Flutter
  engine is started until a search result is selected.
- No protocol, crypto, snapshot-format, database-migration, dependency or server
  changes. The same Android signing key is used, so installing over the previous
  version works normally; macOS still requires manual installation from the DMG
  (self-signed build).

## Polski

- Lista notatek w widżecie Androida nie ucina już góry pierwszej karty. Odstępy
  między wierszami przeniosły się z marginesu wiersza do samej listy
  (przezroczysty divider + padding listy); margines na wierszu RemoteViews jest
  owijany przez launcher i wypychał pierwszą kartę na krawędź przycięcia, nawet
  przy liście przewiniętej do samej góry.
- Natywna wyszukiwarka widżetu jest teraz małym floating okienkiem nad pulpitem,
  z którego otwarto widżet, a nie pełnoekranowym oknem: przezroczyste okno z
  przyciemnionym tłem i całkowicie nieprzezroczystą kartą, więc ekran z tyłu
  pozostaje widoczny, ale nie da się przez kartę odczytać treści notatek. Tap
  poza kartą zamyka okno.
- Okno wyszukiwania nie zakrywa już paska statusu: system umieszcza je w
  bezpiecznym obszarze, jest węższe od ekranu, a lista wyników ma maksymalnie
  połowę wysokości ekranu, więc pole wyszukiwania zostaje widoczne przy
  klawiaturze; klawiatura przesuwa kartę, zamiast ją rozciągać.
- Prywatność bez zmian: FLAG_SECURE zostaje, karta jest nieprzezroczysta, a
  silnik Fluttera nie startuje do momentu wyboru wyniku wyszukiwania.
- Bez zmian protokołu, kryptografii, formatu snapshotu, bazy, zależności i
  serwera. Ten sam klucz podpisu Androida, więc instalacja na poprzednią wersję
  działa normalnie; macOS nadal wymaga ręcznej instalacji z DMG (build
  self-signed).
