# Silique 0.2.27+36 — opublikowane, proweniencja i weryfikacja

Stan sprawdzony po publikacji: 2026-10-26, około 22:10 CET. Wydanie publiczne
`v0.2.27`, opublikowane `2026-10-26T21:04:57Z`, nie jest draftem ani prerelease.
Ma **8 zasobów: 7 instalatorów i `SHA256SUMS.txt`**.[1]

## Zgoda właściciela i granica weryfikacji

Właściciel nie wykonał osobistego testu na urządzeniu. Publikacja nastąpiła na
jego polecenie **„Jeśli zadanie zakończone, opublikuj”**, po wcześniejszym
potwierdzeniu **„Tak”** w tym samym zadaniu. Zapisujemy tę konkretną zgodę na
publikację bez osobistego testu, a nie wykonanie testu ani stałą zgodę na kolejne
wydania. Cytaty pochodzą z poleceń właściciela przekazanych w kontekście zadania;
nie z logów GitHub Actions.

## Zakres wydania

Wybór lokalnego lub systemowego magazynu poświadczeń: przy pierwszej konfiguracji
wstępnie wybrany plik lokalny z ostrzeżeniem, później przełączanie w Ustawieniach.
Migracja dotyczy jednego logicznego zestawu poświadczeń; zachowuje klucze, dane
notatek i ochronę hasłem ukrytych notatek. Istniejące instalacje pozostają przy
magazynie systemowym do jawnej zmiany. Szczegóły kontraktu i ograniczenia:
[CREDENTIAL_STORAGE.md](CREDENTIAL_STORAGE.md). Opublikowany opis zmian jest
również w obu kanałach aktualizacji.[2][3]

## Weryfikacja po publikacji — wykonana

### 1. Podpisy i kanały

Publiczne pliki pobrano anonimowo. **3/3 weryfikacje Ed25519 zaliczone** kluczem
publicznym updatera odczytanym z `lib/core/updates.dart`:

`gISI1x7vljf/QRt50r3fmP4D8v8LwCJIkAFO2qUaCpc=`

- `latest.json`: podpis oryginalnych bajtów payloadu po base64-decode; dodatkowo
  rzeczywisty `dart run tool/check_update_feed.dart` zwrócił
  `Verified publisher signature: 0.2.27, build 36`.[2]
- `appcast.xml`: podpis kanału Sparkle z końcowego `sparkle-signatures`, dla
  dokładnie **2282 bajtów** wskazanych przez `length`. Sprawdzono, że reszta
  pliku to wyłącznie trailer podpisu, bez dodatkowej niepodpisanej treści.[3]
- Podpis `sparkle:edSignature` pobranego archiwum macOS wskazanego przez
  enclosure również prawidłowy; URL i rozmiar zgodne z podpisanym manifestem.[3]

Do niezależnej weryfikacji użyto `openssl pkeyutl -verify -pubin -keyform DER
-rawin`; żadnych kluczy prywatnych nie odczytywano. `latest.json` wskazuje
**0.2.27/build 36** i dokładnie **7 platform**: `android`, `linux`, `linux-deb`,
`linux-rpm`, `macos`, `windows`, `windows-portable`. SHA256 wszystkich siedmiu
wpisów są zgodne z `SHA256SUMS.txt`. Appcast ma jeden bieżący element macOS,
`shortVersionString=0.2.27`, `version=36`; nie jest manifestem siedmiu platform.[2][3]

Uwaga interpretacyjna: `AppRelease.verify` udostępnia w modelu klienta tylko
obsługiwane platformy, bez Windows. Liczbę siedmiu potwierdzono w **podpisanym
surowym payloadzie `platforms`**, nie przez rozmiar mapy `artifacts` klienta.

### 2. Anonimowy smoke updatera

Uruchomiono istniejący test, bez zmian kodu i bez tokenu GitHub w procesie:

```sh
env -u GH_TOKEN -u GITHUB_TOKEN -u GH_ENTERPRISE_TOKEN \
  -u GITHUB_ENTERPRISE_TOKEN SILIQUE_PUBLIC_UPDATER_SMOKE=1 \
  flutter test test/updater_public_smoke_test.dart --reporter expanded
```

Wynik: **1 zaliczony, 0 pominiętych, 0 błędów**, około 5 s, `All tests passed!`.
Rzeczywisty `UpdateClient.latest()` zweryfikował publiczny podpis;
`UpdateClient.download()` pobrał APK do świeżego katalogu, sprawdził rozmiar i
SHA256 przed zmianą nazwy, bez pozostawienia `.part`. Klient nie dodaje nagłówka
Authorization i nie czyta konfiguracji `gh`. APK w podpisanym kanale ma
**65 955 955 bajtów** i SHA256 podany poniżej.[2]

To test pobierania i integralności, **nie instalacja na telefonie**. Poprzedni
etap sprawdził `aapt2`: pakiet `pl.novanotes.nova_notes`, `versionName=0.2.27`,
`versionCode=36`; nie powtarzano tej inspekcji w tym etapie.

### 3. macOS — wyłącznie główny bundle

W anonimowo pobranym `Silique-0.2.27-macOS.zip` odczytano dokładnie jeden wpis
**`Silique.app/Contents/Info.plist`**: `CFBundleShortVersionString=0.2.27`,
`CFBundleVersion=36`. `SUPublicEDKey` odpowiada kluczowi updatera. Nie odczytywano
Info.plist z zagnieżdżonego Sparkle/Updater.app i nie rozpakowywano aplikacji
na dysk. ZIP: **24 201 471 bajtów**, SHA256 zgodny z sumami i podpisanym kanałem.[1][2]

### 4. Windows — 2/2 pliki zgodne

EXE i ZIP pobrano anonimowo z publicznego wydania; SHA256 obliczono z faktycznie
pobranych bajtów i porównano zarówno z `SHA256SUMS.txt`, jak i podpisanym
payloadem. Setup ma **12 911 321 bajtów**, ZIP **15 672 201 bajtów**; oba rozmiary
są zgodne z manifestem. Nie uruchamiano instalatora na tym hoście Linux.[1][2]

## Dowody lokalne i pozostałe ograniczenia

Dowody tej kontroli, niecommitowane pliki pomocnicze w worktree:
`.dart_tool/postpublication-0.2.27/` — `verification.json`, `verify.py`,
`updater-smoke.log`, pobrane kanały, sumy i trzy archiwa/instalatory.
Nie są publikowane do publicznego repo instalatorów.

- **Nieweryfikowane:** osobisty test właściciela na urządzeniu (nie odbył się),
  interaktywna instalacja i restart na macOS/Windows/Android, systemowe dialogi
  UAC/CFA oraz natywna instalacja DEB/RPM w tej sesji. Smoke sieciowy i inspekcja
  archiwum nie potwierdzają tych zachowań.
- Nie wykonywano deployu ani zmian produkcji, nie uruchamiano CT 104, nie
  zmieniano sekretów, kluczy ani konfiguracji `gh`. Nie tworzono kolejnego
  wydania ani draftu i nie modyfikowano podpisanych kanałów.
