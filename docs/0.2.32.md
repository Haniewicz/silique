## Zakres i zgoda

Windows od tej wersji oferuje jawne pobieranie i uruchamianie aktualizacji
z Ustawień. Podpisany manifest, kanoniczny URL, rozmiar i SHA256 są sprawdzane
ponownie na natywnej granicy. Tożsamość uruchomionej instalacji wymaga
64-bitowej rejestracji HKLM, dokładnego modułu/katalogu i chronionych ACL.
Chroniony niestandardowy katalog pozostaje ten sam; portable ZIP, kopie
AppData, nieaktualne wpisy, dowiązania i nierozpoznane ACL pozostają ręczne.

Przed instalacją aplikacja blokuje nowe mutacje, drenuje przyjęte operacje,
zapisuje edytor, blokuje ukryte klucze i wymaga checkpointu SQLite. Odmowa
UAC lub błąd uruchomienia odwracają przygotowanie. Udane uruchomienie nie
przywraca edycji, nawet jeśli zamknięcie okna zawiedzie: dostępna jest tylko
ponowna próba zamknięcia. Nie zabijamy niezapisanej aplikacji ani nie uruchamiamy
jej po instalacji z podwyższonym tokenem. Użytkownik otwiera zwykły skrót.
Starszy klient Windows bez tej funkcji wymaga ręcznej instalacji tego Setup;
aktualizacja w aplikacji jest dostępna dopiero od 0.2.32.

Właściciel jawnie polecił: **„Kiedy wszystko będzie zrobione. Opublikuj wydanie
bez mojej akceptacji”**. Zgoda dotyczy tego wydania i zwolnienia z oczekiwania
na osobisty test, nie kolejnych wydań. **Osobisty test nie odbył się.**
Nie dotykano urządzeń właściciela, danych ani serwera produkcyjnego.

## Ograniczenia i wcześniejsze próby

Nie wykonano interaktywnego UAC, UAC z innym administratorem, instalacji na
urządzeniu właściciela ani aktualizacji jego prawdziwego notatnika. Już
podwyższony runner potwierdza protokół Inno, nie te scenariusze. Syntetyczny
plik zachowania w teście Setup nie zastępuje testów prawdziwego SQLite;
te wykonano oddzielnie. Nie wykonano interaktywnej instalacji DEB/RPM ani
Sparkle restartu aplikacji na danych właściciela.

Setup pozostaje bez Authenticode na wcześniejszą decyzję właściciela; UAC może
pokazać nieznanego wydawcę. macOS zachowuje lokalny certyfikat preview, bez
Developer ID/notaryzacji; prawidłowy podpis nie dowodzi akceptacji Gatekeeper.
Nie wyłączano ochrony. Starszy macOS do 0.2.29 wymaga ręcznego przejścia na DMG.

Historyczne nieudane Windows runy nie weszły do wydania:
`40623138702`, `40624336504` (fixture/platform separators), `40624796961`
(wersja z sufiksem Flutter build), `40625359137` (MSVC fixture ASCII),

lub późniejsza bramka identity), `40644660580` (stara ścieżka cached image
po junction fixture), `40645950937`, `40647166272` (piny katalogu docelowego
