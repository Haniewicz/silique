# Silique 0.2.63

## English

- The editor toolbar can colour text and highlight it with a translucent
  colour. Select a run, open the palette and pick a colour for the text or for
  a soft highlighter background; the live Markdown view paints the run as soon
  as the choice is made.
- Colours are stored as inline HTML inside the note
  (`<span style="color:#RRGGBB">…</span>` and
  `<span style="background-color:rgba(R,G,B,A)">…</span>`), the same lossless
  Markdown form the existing inline text-size formatting uses. They survive
  sync, export and import unchanged, a multi-line selection is wrapped line by
  line with empty lines skipped, and picking a new colour for an already
  coloured run rewrites that run instead of nesting another span.
- The text-size field gained up/down arrows that step the size by one pixel
  (8–72 px). With text selected the new size is applied immediately, and the
  field follows the size of the run that contains the current selection.
- Toolbar actions no longer drop a text selection: tapping bold, italics, a
  heading, a list, a colour or the size arrows keeps the same text selected,
  and focus returns to the document after actions that open a menu or a
  dialog, so the selection stays visible.
- Rows inside every Settings section now share one rounded hover surface with a
  slightly wider left inset and a small gap between rows, including the
  informational device and pairing rows. The section sidebar tiles use the
  same radius.
- The four sidebar footer actions keep a small inset from the bottom window
  edge instead of sitting flush against it.
- Text alignment (left/centre/right) is not part of this release: the note body
  is a single text field with one alignment for the whole document, so aligning
  individual lines would need a different editor layout. That work is deferred
  rather than faked.
- No protocol, crypto, database-migration, dependency or server changes. Same
  Android signing key, so installing over the previous version works normally.
  macOS still requires manual installation from the DMG (self-signed build).

## Polski

- Pasek narzędzi edytora potrafi zmienić kolor tekstu i zakreślić go
  półprzezroczystym kolorem. Zaznacz fragment, otwórz paletę i wybierz kolor
  tekstu albo miękkie tło zakreślenia; podgląd na żywo maluje fragment od razu
  po wyborze.
- Kolory są zapisane jako inline HTML w notatce
  (`<span style="color:#RRGGBB">…</span>` oraz
  `<span style="background-color:rgba(R,G,B,A)">…</span>`) — ta sama bezstratna
  forma Markdown, której używa już formatowanie rozmiaru tekstu. Przeżywają
  synchronizację, eksport i import bez zmian; zaznaczenie wielolinijkowe jest
  zawijane linia po linii z pominięciem pustych, a wybór nowego koloru dla już
  pokolorowanego fragmentu nadpisuje ten fragment zamiast zagnieżdżać kolejny
  span.
- Pole rozmiaru tekstu ma strzałki góra/dół, które zmieniają rozmiar o jeden
  piksel (8–72 px). Przy zaznaczonym tekście nowy rozmiar stosuje się od razu,
  a pole pokazuje rozmiar fragmentu obejmującego bieżące zaznaczenie.
- Akcje paska narzędzi nie odznaczają już tekstu: kliknięcie pogrubienia,
  kursywy, nagłówka, listy, koloru albo strzałek rozmiaru zostawia to samo
  zaznaczenie, a po akcjach otwierających menu lub okno focus wraca do
  dokumentu, więc zaznaczenie pozostaje widoczne.
- Wiersze w każdej sekcji Ustawień mają teraz jedną zaokrągloną powierzchnię
  hover z nieco szerszym lewym wcięciem i małym odstępem między wierszami —
  również informacyjne wiersze urządzeń i parowania. Kafle sekcji w bocznym
  pasku używają tego samego promienia.
- Cztery akcje stopki sidebara mają mały odstęp od dolnej krawędzi okna,
  zamiast przylegać do niej.
- Wyrównanie tekstu (lewo/środek/prawo) nie wchodzi w to wydanie: ciało
  notatki to jedno pole tekstowe z jednym wyrównaniem dla całego dokumentu, więc
  wyrównywanie pojedynczych linii wymagałoby innego układu edytora. Ta praca
  jest odłożona, a nie udawana.
- Brak zmian protokołu, kryptografii, migracji bazy, zależności i serwera. Ten
  sam klucz podpisu Androida, więc instalacja na poprzednią wersję działa
  normalnie. macOS nadal wymaga ręcznej instalacji z DMG (build z podpisem
  własnym).
