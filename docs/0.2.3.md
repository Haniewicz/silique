# Silique 0.2.3 — podgląd zdjęć

Naprawiono wyświetlanie zdjęć z długimi nazwami i odwołaniami do załączników. Edytor wyświetla obraz także wtedy, gdy jego zapis Markdown nie mieści się w jednym wierszu. Poprawka obejmuje istniejące notatki, zdjęcia dodawane przyciskiem oraz przeciągane do edytora. Nie wymaga ponownego importu ani zmiany danych na serwerze.

Testy regresji sprawdzają zdekodowane obrazy, dwa zdjęcia w kolejnych wierszach, długie nazwy zrzutów ekranu, szerokość komputera i telefonu oraz położenie kursora w zapisie zdjęcia. Test przeciągania sprawdza rzeczywisty podgląd obu zaszyfrowanych załączników ponad 600 kB.

Weryfikacja: 28 testów aplikacji zakończonych powodzeniem, analiza Flutter bez uwag. Trzy testy integracyjne wymagające uruchomionego serwera pominięto w tym przebiegu; poprawka dotyczy wyłącznie wyświetlania w edytorze.
