# Silique 0.2.62

## English

- The floating label that appears over a sidebar footer action (Deleted,
  Hidden, Import, Settings) now uses the app's own UI font in its intended size
  and weight instead of a fallback typeface, and it is no longer underlined.
  The label existed before, but it picked up a diagnostic text style because it
  is drawn in the window overlay rather than inside the sidebar's `Material`;
  the label now carries its own explicit style.
- The label pill is exactly as wide as its text and always stays completely
  inside the window: the rounded ends of the edge actions' labels are no longer
  cut off by the window edge, and the pill follows its action when the window
  is resized while hovering.
- Rows in Settings (switches and tappable colour rows) now show the same
  rounded hover surface the folder rows and section tiles use, instead of a
  square rectangle.
- No protocol, crypto, database-migration, dependency or server changes. Same
  Android signing key, so installing over the previous version works normally.
  macOS still requires manual installation from the DMG (self-signed build).

## Polski

- Pływająca etykieta nad akcją stopki sidebara (Usunięte, Ukryte, Importuj,
  Ustawienia) używa teraz własnego kroju UI aplikacji w zamierzonym rozmiarze i
  wadze zamiast kroju zapasowego i nie jest już podkreślona. Etykieta istniała
  wcześniej, ale przejmowała diagnostyczny styl tekstu, bo jest rysowana w
  nakładce okna, a nie wewnątrz `Material` sidebara; teraz ma jawny styl.
- Tło etykiety jest dokładnie tak szerokie jak jej tekst i zawsze mieści się w
  całości w oknie: zaokrąglone końce etykiet skrajnych akcji nie są już
  obcinane krawędzią okna, a przy zmianie rozmiaru okna pill podąża za swoją
  akcją.
- Wiersze w Ustawieniach (przełączniki i klikalne wiersze kolorów) mają teraz
  tę samą zaokrągloną powierzchnię hover, którą używają wiersze folderów i kafle
  sekcji, zamiast prostokąta z ostrymi rogami.
- Brak zmian protokołu, kryptografii, migracji bazy, zależności i serwera. Ten
  sam klucz podpisu Androida, więc instalacja na poprzednią wersję działa
  normalnie. macOS nadal wymaga ręcznej instalacji z DMG (build z podpisem
  własnym).
