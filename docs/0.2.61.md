# Silique 0.2.61

## English

- The Deleted / Hidden / Import / Settings footer is now pinned to the bottom of
  the sidebar in both sidebar variants and no longer scrolls away with the
  folder tree. The four buttons are icon-only (no visible captions): hovering
  one shows a small floating label with its name, and the name stays available
  to screen readers. Hover and selection surfaces keep the same rounded
  folder-row styling.
- Settings rows, tiles, switches and buttons now use one hover surface, the same
  colour and corner radius the folder rows use, with the ripple splash removed
  so hovering reads identically everywhere.
- The Settings dialog is wider on desktop and its sections moved from a tab
  strip into a left sidebar (General, Appearance, Shortcuts, Account, Storage,
  Updates) next to the content. On a phone the dialog shows the section list and
  a section only opens after tapping it, with a back header returning to that
  list. Section state (fields, scroll offset) is preserved as before.
- Windows in-app update now completes without walking through the installer:
  Setup runs silently (`/SILENT /SUPPRESSMSGBOXES`), the UAC consent prompt
  remains, and after a successful install the updated app starts again
  automatically with the normal user's token (never an elevated one). Relay is
  limited to a successful in-app install; a cancelled UAC prompt or a failed
  install launches nothing and the app is opened from the shortcut as before.
  Vaults, keys, preferences and the install identity are preserved; no protocol
  or crypto changes.
- In the Ctrl+K quick switcher, starting the query with `#` searches the tags
  available in the vault's notes: suggestions are narrowed as you type (case-
  insensitive), show how many notes use each tag, and Enter on a suggestion
  filters the switcher to the notes carrying that tag. Escape clears the tag
  filter and then the `#` query before closing the switcher.
- No protocol, crypto, database-migration or server changes. No new
  dependencies. Same Android signing key, so installing over the previous
  version works normally. macOS still requires manual installation from the DMG
  (self-signed build).

## Polski

- Stopka Usunięte / Ukryte / Importuj / Ustawienia jest teraz przyklejona do
  dołu sidebara w obu wariantach i nie odjeżdża już przy przewijaniu drzewa
  folderów. Cztery przyciski są ikonami bez widocznych podpisów: najechanie
  myszą pokazuje małą pływającą etykietę z nazwą akcji, a nazwa pozostaje
  dostępna dla czytników ekranu. Hover i zaznaczenie zachowują zaokrąglony styl
  wierszy folderów.
- Rzeczy w Ustawieniach (wiersze, kafle, przełączniki, przyciski) mają teraz
  jednolite tło hovera — ten sam kolor i promień zaokrąglenia co wiersze
  folderów, bez splashu, więc hover wygląda wszędzie tak samo.
- Modal Ustawień jest szerszy na desktopie, a sekcje przeniesły się z paska
  zakładek do lewego sidebara (Ogólne, Wygląd, Skróty, Konto, Pamięć,
  Aktualizacje) obok treści. Na telefonie modal pokazuje listę sekcji i dopiero
  kliknięcie w sekcję ją otwiera, a nagłówek z powrotem wraca do listy. Stan
  sekcji (pola, pozycja przewinięcia) jest zachowany jak dotąd.
- Aktualizacja z aplikacji na Windowsie przechodzi teraz bez kreatora
  instalatora: Setup uruchamia się cicho (`/SILENT /SUPPRESSMSGBOXES`), zgoda
  UAC nadal się pojawia, a po udanej instalacji zaktualizowana aplikacja
  uruchamia się ponownie automatycznie z tokenem zwykłego użytkownika (nigdy
  podniesionym). Restart dotyczy wyłącznie udanej instalacji z aplikacji;
  anulowana zgoda UAC lub nieudana instalacja niczego nie uruchamiają i aplikację
  otwiera się ze skrótu, jak dotychczas. Vaulty, klucze, preferencje i tożsamość
  instalacji są zachowane; bez zmian protokołu i kryptografii.
- W quick switcherze pod Ctrl+K wpisanie na początku `#` szuka po tagach
  dostępnych w notatkach vaulta: podpowiedzi zwężają się w miarę pisania (bez
  względu na wielkość liter), pokazują liczbę notatek z danym tagiem, a Enter na
  podpowiedzi filtruje listę do notatek z tym tagiem. Escape najpierw czyści
  filtr tagu, potem zapytanie `#`, a dopiero potem zamyka switcher.
- Bez zmian protokołu, kryptografii, migracji bazy i serwera. Bez nowych
  zależności. Ten sam klucz podpisu Androida, więc instalacja nad poprzednią
  wersją działa normalnie. macOS nadal wymaga ręcznej instalacji z DMG
  (build self-signed).
