# Silique 0.2.59

## English

- Notes list grouping fixed: Pinned / Today / Yesterday / Older now show **one
  header per group**. Previously the group name was repeated above every note in
  the group, which made a grouped list look like a pile of one-note groups.
- The `Szablony` folder is created by default. A new vault already contains it;
  an existing vault gets it the first time it is opened and unlocked. The folder
  is built in: it cannot be deleted or renamed, and Settings → General can hide
  it from the folder tree (templates keep working, the notes stay reachable
  through "All notes" and search).
- Creating notes from a template was removed: the "New note from template…"
  entries are gone from the note, folder and note-options menus, and so is
  "Journal entry from template…" from the drawer. Templates are now used in two
  ways instead: a default template for new notes (Settings) and applying one to
  an existing note.
- Settings → General gains a **default note template** for ordinary notes
  (default: None), next to the existing default journal template. The chosen
  template is filled in silently when a new ordinary note is created; the note
  keeps the current folder, so filling it never turns the note into a template.
- New "Apply template…" action on an existing note, in the note context menu
  (right-click / long-press) and in the note-options menu. An empty note gets the
  template title and rendered body; a note that already has content keeps its
  title and gets the rendered template appended at the end, separated by a blank
  line. Unsaved editor changes are flushed first, and the write goes through the
  normal note path, so revisions, encryption and sync behave as usual.
- Ctrl+K quick switcher: the search field is focused immediately when the panel
  opens, so typing goes straight into the query instead of the editor.
- No protocol, crypto, database-migration or server changes. No new dependencies.
  Same Android signing key, so installing over the previous version works
  normally. macOS still requires manual installation from the DMG (self-signed
  build).

## Polski

- Naprawione grupowanie listy notatek: Przypięte / Dziś / Wczoraj / Starsze mają
  teraz **jeden nagłówek na grupę**. Wcześniej nazwa grupy powtarzała się nad
  każdą notatką w grupie, przez co pogrupowana lista wyglądała jak stos
  jednoelementowych grup.
- Folder `Szablony` jest tworzony domyślnie. Nowy vault zawiera go od razu;
  istniejący vault dostaje go przy pierwszym otwarciu i odblokowaniu. Folder jest
  wbudowany: nie można go usunąć ani przemianować, a Ustawienia → Ogólne mogą go
  ukryć w drzewie folderów (szablony działają dalej, notatki pozostają dostępne
  przez „Wszystkie” i wyszukiwanie).
- Usunięte tworzenie notatek z szablonu: zniknęły pozycje „Nowa notatka
  z szablonu…” z menu notatki, folderu i opcji notatki oraz „Wpis dziennika
  z szablonu…” z szuflady. Zamiast tego szablony są używane na dwa sposoby:
  domyślny szablon nowych notatek (Ustawienia) i zastosowanie szablonu do
  istniejącej notatki.
- Ustawienia → Ogólne mają nowy **domyślny szablon notatki** dla zwykłych
  notatek (domyślnie: Brak), obok dotychczasowego domyślnego szablonu wpisu
  dziennika. Wybrany szablon jest cicho wypełniany przy tworzeniu nowej zwykłej
  notatki; notatka zachowuje bieżący folder, więc wypełnienie nie zamienia jej
  w szablon.
- Nowa akcja „Zastosuj szablon…” dla istniejącej notatki — w menu kontekstowym
  notatki (prawy przycisk / długie przytrzymanie) i w menu opcji notatki. Pusta
  notatka dostaje tytuł i wyrenderowaną treść szablonu; notatka z treścią
  zachowuje tytuł, a wyrenderowany szablon jest dopisywany na końcu po pustej
  linii. Niezapisane zmiany edytora są najpierw utrwalane, a zapis idzie zwykłą
  ścieżką notatki, więc rewizje, szyfrowanie i synchronizacja działają jak dotąd.
- Quick switcher (Ctrl+K): pole wyszukiwania jest od razu zfokusowane po
  otwarciu panelu, więc pisanie trafia do zapytania, a nie do edytora.
- Bez zmian protokołu, kryptografii, migracji bazy i serwera. Bez nowych
  zależności. Ten sam klucz podpisu Androida, więc instalacja na poprzednią
  wersję działa normalnie. macOS nadal wymaga ręcznej instalacji z DMG (build
  self-signed).
