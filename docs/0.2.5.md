# Silique 0.2.5 — build 10

Wydanie opublikowane 2026-10-21 po potwierdzeniu właściciela: [Silique 0.2.5](https://github.com/Haniewicz/silique-releases/releases/tag/v0.2.5). Kod aplikacji i serwera pozostaje prywatny. Publiczne repozytorium zawiera instalatory, instrukcję, ręczny workflow Windows i podpisane kanały aktualizacji.

## Paczki

- macOS: uniwersalny ZIP (Apple Silicon/Intel), macOS 12+.
- Android: APK z dotychczasowym certyfikatem, Android 7+.
- Windows x64: instalator EXE dla bieżącego użytkownika i przenośny ZIP.
- Linux GTK4 x64: DEB dla Ubuntu 24.04+, RPM sprawdzony na Fedorze 44 i tar.gz. Wymaga GTK4 >= 4.14, glibc >= 2.39 i Secret Service. Niestandardowy port Flutter GTK4 pozostaje eksperymentalny.

Wydanie zawiera SHA256 wszystkich siedmiu paczek. Podpisane kanały `latest.json` oraz `appcast.xml` wskazują wersję 0.2.5, build 10. Pierwsza instalacja po 0.2.4 jest ręczna. macOS/Android wykrywają nowe wersje automatycznie, a instalację potwierdza użytkownik. Windows/Linux aktualizuje się ręcznie przez stronę wydań.

## Weryfikacja

Po publikacji porównano rozmiary i SHA256 wszystkich ośmiu zasobów GitHub (siedem paczek i plik sum). Publiczne kanały oraz plik sum pobrano bez uwierzytelnienia i porównano z przygotowanym wydaniem. Test rzeczywistego klienta updatera pobrał APK bez konta GitHub, zweryfikował podpis kanału oraz rozmiar/SHA256 i przeszedł.

97 testów aplikacji zaliczonych, 10 pominiętych; analiza bez uwag. Windows przeszedł natywny test kluczy, SQLite, edytora i chronionego vaulta oraz instalację, start i deinstalację EXE. Linux przeszedł próby natywne z bibliotekami Ubuntu/Fedory, instalację DEB/RPM i start produkcyjnej aplikacji; osobno przeszedł test headless Wayland bez X11. Pełna automatyzacja klawiatury, dialogów i drop działała w X11; fizyczna sesja GNOME/Wayland wymaga dalszej ręcznej weryfikacji. Szczegóły i źródłowe rewizje paczek: [wydania desktopowe](desktop-packages.md).

Podpisy macOS i APK oraz metadane wersji zweryfikowano przy przygotowaniu paczek. Wcześniejszy build 9 przeszedł także próbę systemowego instalatora Androida na emulatorze z zachowaniem pliku danych; nie zastępuje to osobnego testu instalacji build 10. Pełnego restartu aktualizacji Sparkle na komputerze właściciela nie automatyzowano.

macOS używa lokalnego podpisu bez notaryzacji, Windows nie ma Authenticode, RPM nie ma podpisu OpenPGP. Podpis Ed25519 kanału obejmuje wersję, adresy, rozmiary i SHA256. Klucze i identyfikatory istniejących vaultów pozostają zgodne.

Na komputerze właściciela pozostaje jedna instalacja `/Applications/Silique.app`; skrypty budowania podmieniają ją i usuwają robocze kopie Release/Debug. Archiwa pozostają ZIP. Dokumentacja updatera: [updater.md](updater.md).
